# 작품 카테고리와 표시 형식

세 카테고리의 우측 상단 GIF / YOUTUBE 버튼은 각각 독립적으로 전환됩니다. 기본 선택은 GIF이며, YOUTUBE는 유튜브 플레이어를 표시합니다. 형식을 바꾸면 이전 영상 재생이 중지되고 첫 번째 작품부터 표시됩니다.

Google Sheets DATA 시트의 type과 value를 사용합니다.

| 영역 | GIF type | YOUTUBE type |
| --- | --- | --- |
| 방송화면 및 대기화면 | broadcast_gif | broadcast_youtube |
| 월페이퍼 및 반응형 월페이퍼 | wallpaper_gif | wallpaper_youtube |
| 인게임 | ingame_gif | ingame_youtube |

value에는 GIF 이미지 URL 또는 YouTube 영상 URL을 입력합니다. 같은 type의 행을 추가하면 좌우 화살표로 넘길 수 있습니다.

기존 gif / youtube 행은 방송화면 및 대기화면에 유지됩니다. 기존 broadcast / wallpaper / ingame 행은 해당 카테고리의 YouTube 영상으로 계속 인식합니다. 미디어가 없는 형식에는 빈 카드가 표시됩니다.

preview/categories.html을 다운로드해서 브라우저로 열면 실제 데이터 없이 배치와 전환 버튼을 확인할 수 있습니다.

Netlify 배포 없이 검토하는 작업 브랜치입니다. 명시적인 배포 요청 전에는 main에 병합하지 않습니다.

## 소개글 / 주의사항

자기소개 아래에 소개글, 모든 작품 아래에 주의사항을 표시합니다.
DATA 시트에 type이 `about`인 행을 추가하고 value에 소개글을 입력하세요.
type이 `notice`인 행의 value에는 주의사항을 입력하세요. 셀 안의 줄바꿈은 그대로 표시됩니다.
기존 `intro` 또는 `text`는 자기소개 카드에 계속 사용됩니다. 새 내용이 없으면 안내용 자리표시 문구가 나옵니다.

## 협업작가

주의사항 바로 위에 작가별 미디어 카드와 소개 카드를 한 묶음으로 세로 배치합니다. 별도의 내부 스크롤 박스 없이 페이지 전체를 아래로 스크롤합니다. PC에서는 미디어/소개가 좌우, 모바일에서는 위아래로 표시됩니다. 아트머그 iframe이 고정 높이라면 작가 수와 글 길이에 맞춰 외부 iframe 높이도 늘려야 합니다.

| type | value |
| --- | --- |
| collab_1_name | 작가 이름 (필수) |
| collab_1_url | 해당 작가의 전체 아트머그 페이지 URL |
| collab_1_intro | 작가 소개, 줄바꿈 가능 |
| collab_1_gif | GIF 이미지 URL 하나 |
| collab_1_youtube | 유튜브 영상 URL 하나 |
| collab_1_note | 자유로운 비고 내용 (선택) |

두 번째 작가는 collab_2_name, collab_2_url 등으로 입력합니다. 3, 4…번도 같은 방식입니다. 번호 오름차순으로 나옵니다. 각 항목은 작가당 한 행씩 입력하며 중복 시 첫 번째 값을 사용합니다. 이름이 없는 작가는 표시하지 않습니다.

작가별 GIF / YOUTUBE 버튼은 독립적으로 작동합니다. 이름 클릭 시 아트머그 페이지가 새 탭으로 열립니다. URL은 artmug.kr 또는 www.artmug.kr의 http/https 주소만 허용합니다. 링크가 없거나 잘못되면 이름을 클릭할 수 없고 등록 예정 안내를 표시합니다.

비고에는 “작가님 이름 클릭 시 페이지로 이동합니다.”가 항상 표시되며, note 내용은 그 아래에 추가됩니다. 예시 미리보기에는 실존 작가 정보 대신 두 작가의 빈 카드가 표시됩니다.

## 미디어 로딩과 빈 상태

GIF/YouTube URL이 없으면 “준비 중입니다···”를 표시합니다. 빈 작품 목록에는 슬라이드 탐색 버튼을 표시하지 않습니다. GIF는 최초 로딩 시 16:9 공간을 확보하고, 이후 이미지 변경 시 이전 이미지 비율을 로딩 완료까지 유지합니다. 로딩이 끝나면 새 이미지의 원본 비율에 맞추므로 잘리지 않습니다. 원본 비율이 다르면 로딩 완료 후 높이는 달라질 수 있습니다. YouTube는 16:9 공간을 유지합니다. 실제 미디어 로드 실패는 별도의 오류 문구로 표시됩니다. 협업작가 안내 영역은 ‘비고’ 제목 없이 안내와 추가 내용만 표시합니다.

## 프로필 이미지 및 작품별 설명

프로필 사진: type=profile_image, value=전체 이미지 URL.
작품별 번호 지정: broadcast_1_gif / broadcast_1_youtube / broadcast_1_description.
두 번째 작품은 broadcast_2_gif / broadcast_2_youtube / broadcast_2_description.
월페이퍼와 인게임은 접두사를 wallpaper / ingame으로 바꿉니다. 각 번호의 GIF와 YouTube 및 설명이 하나의 작품입니다. 미디어 전환 시 작품 번호가 유지되고 없는 형식은 준비 중으로 표시됩니다.
기존 번호 없는 type도 지원하며 같은 형식의 시트 등장 순서대로 1, 2…번에 배정됩니다. 같은 번호의 명시적 항목이 있으면 명시적 항목이 우선합니다.
세로 스크롤은 허용하고 스크롤바만 숨깁니다. 아트머그 iframe에 scrolling=no가 남아 있다면 제거하거나 scrolling=yes로 바꿔야 합니다.
새 정적 이미지는 public 폴더에 추가한 후 Netlify 배포가 완료되어야 사이트 주소로 이용할 수 있습니다. 이미 온라인에 있는 이미지 URL만 시트에 바꿀 때는 재배포가 필요 없습니다.

## GIF 미리 로딩

시트 데이터를 받은 후 현재 화면을 렌더링하고, 모든 카테고리와 협업작가의 GIF 주소를 Image 객체로 미리 요청합니다. 중복 URL은 한 번만 요청하고 현재 보이는 이미지와 경쟁을 줄이기 위해 백그라운드 요청에는 low 우선순위를 사용합니다. 별도 시트 설정은 필요 없습니다. 첫 다운로드가 끝나기 전에는 전환 시 대기가 남을 수 있고 실제 캐시 재사용은 브라우저에 따라 달라집니다. 방문자가 보지 않는 GIF도 내려받으므로 방문당 전송량이 증가할 수 있습니다.
유튜브는 플레이어/썸네일 서버에 preconnect 힌트만 추가하며 전체 영상 다운로드를 선행하지 않습니다. 예시 미리보기에는 실제 GIF가 없어 다운로드 속도 측정용은 아닙니다.

## 날짜 / 진행 방식 / 글자 서식

### 작품 날짜
`broadcast_1_date`의 value에 `2026년 11월`처럼 입력합니다. wallpaper / ingame도 같은 방식입니다. 날짜는 설명 아래에 표시하고 날짜 너비보다 0.8em 긴 짧은 구분선을 둡니다. 날짜가 비어 있으면 날짜와 선을 숨깁니다.

### 작업 진행 방식
소개글 아래의 단계 예시: process_1, process_2, process_3, process_4, process_5. value에 각 단계 제목을 입력합니다. 시트에 입력된 단계만 번호 순서대로 표시합니다.
전체 수정 안내: process_revisions (예: 기본 수정 2회 / 추가 수정 별도 협의).
선택적인 단계별 수정 안내: process_1_revisions … process_5_revisions. value에는 ‘수정 1회’ 등 원하는 문구를 입력합니다. 기본 수정 횟수는 임의로 정하지 않았으며 미리보기의 횟수는 예시입니다.

### 서식 지정: 시트 툴바가 아닌 type/value 행
텍스트 type 뒤에 _color / _font_size를 붙여 별도 행을 추가합니다.
- about_color = #303238 (색상은 #RGB 또는 #RRGGBB)
- about_font_size = 18 (10~48, px 숫자만)
같은 방식으로 name, job, intro, about, notice, process_1 … process_5, process_revisions, process_1_revisions … process_5_revisions, broadcast_1_date, broadcast_1_description, wallpaper_1_date, wallpaper_1_description, ingame_1_date, ingame_1_description, collab_1_name, collab_1_intro, collab_1_note 등에 적용할 수 있습니다. 작품/작가 번호는 각 항목 번호로 바꿉니다. 각 텍스트 블록 전체에 적용되며 한 문장 안의 일부 단어별 서식은 지원하지 않습니다.
전체 본문 기본값: text_color / text_font_size. 개별 설정이 있으면 해당 설정이 우선합니다.
테마: accent_color (번호/선택 글자, 기본 #c93c4b), accent_background (선택 배경, 기본 #fff0f2), accent_border (선택 테두리, 기본 #e77a87).
잘못된 색상/크기는 무시하고 기본값을 유지합니다. 기존 Apps Script는 변경하지 않아도 됩니다. 시트 툴바의 색/글꼴/굵기 변경은 자동으로 읽지 않습니다.

주의사항 notice는 ^로 항목을 구분하며 항목 안 줄바꿈을 유지합니다. 협업작가 note는 기본 본문 크기/색상을 따릅니다. 프로필 이미지는 profile_image의 value에 로그인 없이 이미지 자체가 열리는 전체 URL을 입력합니다. public/profile.png를 배포했다면 https://warm-squirrel-5cfab5.netlify.app/profile.png 를 사용합니다.

## 월 단위 날짜와 카드 그라데이션
작품 날짜는 `2026년 11월` 형식으로 입력합니다. 기존 `2026년 11월 08일` 값도 화면에서는 끝의 일자를 제거해 `2026년 11월`로 표시합니다. 날짜 구분선은 표시된 문자열 너비보다 0.8em만 길게 자동 조정됩니다. 카드 배경은 흰색/회색 계열이며 그라데이션을 사용하지 않습니다. 섹션 제목 하단 선에는 accent_border 색상을 사용합니다.

## 최신 변경: 유동적인 단계 / 설명 먼저 표시
카드 배경 그라데이션만 제거했습니다. 빨간 번호, 선택 버튼과 구분선은 유지합니다.
작품 소개는 설명 → 짧은 구분선 → 날짜(연/월) 순서입니다. 설명과 날짜는 기본 18px/굵게이며 개별 _font_size 설정이 있으면 우선합니다.
작업 진행 단계는 process_1, process_2 …의 비어 있지 않은 값만 번호 순으로 표시합니다. 행을 삭제하거나 value를 비우면 해당 단계 상자가 사라집니다. process_6 등으로 추가할 수 있으며 남은 상자들이 가로폭을 균등 분배합니다. 모바일 또는 7단계 이상은 가독성을 위해 세로로 표시합니다. 단계별 수정 횟수는 원래 번호에 연결됩니다. 모든 단계가 없으면 준비 중 문구가 표시됩니다.

## 신청양식 / 주의사항 구분 / 드래그 방향
신청양식은 주의사항 위에 표시합니다. 아직 form 항목이 없으면 ‘사용 목적’, ‘파츠분리 여부’ 두 항목을 기본 표시합니다. 시트에서 관리하려면 아래 type/value 행을 추가하세요.
- form_1_title: 사용 목적
- form_1_description: 방송용인지, 대기화면인지
- form_1_placeholder: 내용을 입력해 주세요. (선택)
- form_2_title: 파츠분리 여부
- form_2_description: psd 파일의 파츠 분리 여부
form_3_title 등으로 항목을 추가합니다. 제목이 비어 있는 항목은 표시하지 않습니다. 제목을 비우면 해당 항목을 숨길 수 있습니다. 모든 form 항목을 완전히 삭제하면 기본 2개가 다시 표시됩니다.
양식 제목/설명/textarea는 기본 18px, 굵게입니다. form_1_title_color/font_size, form_1_description_color/font_size, form_1_text_color/font_size로 각각 서식을 조절할 수 있습니다.
방문자가 입력한 답변은 브라우저 메모리에만 있으며 시트/서버로 전송하지 않습니다. 새로고침하면 초기화됩니다. 복사하기는 표시된 항목의 [제목] + 줄바꿈 + 답변을 묶고 항목 사이에 빈 줄을 넣습니다. 설명/placeholder는 복사하지 않습니다. 답변이 없는 항목도 제목과 함께 포함합니다. iframe에서 자동 클립보드 접근이 차단되면 전체 텍스트를 보여주므로 직접 복사할 수 있습니다.
주의사항 notice는 이제 줄바꿈이 아니라 ^ 기준으로 구분합니다. 예: 첫 항목\n추가 설명^두 번째 항목. ^는 화면에 표시하지 않으며 항목 안의 실제 줄바꿈은 유지합니다.
왼쪽 드래그로 다음 작품을 선택하면 오른쪽에서 새 작품이 들어옵니다. 오른쪽 드래그로 이전 작품을 선택하면 왼쪽에서 들어옵니다. 버튼 전환 방식은 유지합니다. 작업 단계의 텍스트는 기본 굵게이며 카드 안에서 수직/수평 가운데 정렬됩니다.


## 현재 기본 서식과 복사 동작
- 모든 사이트 글자는 기본 볼드입니다. 개별 굵기 설정 기능은 제거했습니다. 시트에 남아 있는 이전 굵기 설정 행은 무시되며 삭제해도 됩니다. 시트 자체의 행을 자동 삭제하지는 않습니다.
- 01 제목은 ‘작가 소개’입니다. STEP 번호는 카드 상단에 고정하고 그 아래 설명/수정 안내 영역만 중앙 정렬합니다. 전체 수정 횟수 라벨은 작업 진행 본문과 같은 기본 크기입니다.
- 주의사항은 기본 18px/볼드입니다. 마지막 ^ 항목은 기본 #c93c4b이며, DATA에 type `notice_last_color`, value `#FF0000`을 추가하면 마지막 항목만 색상이 바뀝니다. 잘못된 값은 기본 빨간색으로 표시합니다.
- 협업작가 미디어와 소개 카드는 데스크톱에서 같은 폭/행으로 정렬되며 모바일에서는 세로로 배치합니다.
- textarea는 기존 4줄 높이를 최소로 두고 긴 placeholder 또는 입력 내용에 맞춰 늘어납니다.
- 복사 성공 시 초록색 ‘복사 완료!’ 알림이 하단 중앙에서 잠시 올라왔다 사라집니다. iframe 안에서는 iframe 표시 영역을 기준으로 표시됩니다. 복사 실패 시 성공 알림을 표시하지 않습니다. 복사 중 포커스/스크롤 이동을 방지하고 대체 복사 후 원위치로 복원합니다.

## GIF 파일 경로

파일 업로드/교체는 Netlify 배포가 필요합니다. 이미 배포된 파일을 연결하는 시트 URL 변경은 재배포하지 않아도 됩니다. 기존 삭제된 GIF URL은 더 이상 작동하지 않습니다.

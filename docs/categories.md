# 작품 카테고리

Google Sheets DATA 시트의 type과 value를 사용합니다.

| type | 표시 영역 | value |
| --- | --- | --- |
| gif | GIF | GIF 이미지 URL |
| broadcast | 방송화면 및 대기화면 | YouTube URL |
| wallpaper | 월페이퍼 및 반응형 월페이퍼 | YouTube URL |
| ingame | 인게임 | YouTube URL |

기존 youtube 행은 방송화면 및 대기화면에 표시됩니다. 다른 영역으로 옮기려면 해당 행의 type을 변경하세요. 작품이 없는 영역은 빈 카드로 표시됩니다.

preview/categories.html을 다운로드해서 브라우저로 열면 네 카테고리의 배치를 볼 수 있습니다. 이 미리보기는 실제 작품과 시트 데이터를 가져오지 않는 배치 확인용입니다.

이 작업 브랜치는 Netlify 배포 없이 검토하기 위한 것입니다. 배포 요청 전에는 main에 병합하지 않습니다.

# 작품 카테고리와 표시 형식

세 카테고리의 우측 상단 GIF / YOUTUBE 버튼은 각각 독립적으로 전환됩니다. 기본 선택은 GIF이며, YOUTUBE는 유튜브 플레이어를 표시합니다. 형식을 바꾸면 이전 영상 재생이 중지되고 첫 번째 작품부터 표시됩니다.

Google Sheets DATA 시트의 type과 value를 사용합니다.

| 영역 | GIF type | YOUTUBE type |
| --- | --- | --- |
| 방송화면 및 대기화면 | broadcast_gif | broadcast_youtube |
| 월페이퍼 및 반응형 월페이퍼 | wallpaper_gif | wallpaper_youtube |
| 인게임 | ingame_gif | ingame_youtube |

value에는 GIF 이미지 URL 또는 YouTube 영상 URL을 입력합니다. 같은 type의 행을 추가하면 좌우 화살표로 넘길 수 있습니다.

기존 gif / youtube 행은 방송화면 및 대기화면에 유지됩니다. 기존 broadcast / wallpaper / ingame 행은 해당 카테고리의 YouTube 영상으로 계속 인식합니다. 미디어가 없는 형식에는 빈 카드가 표시됩니다.

preview/categories.html을 다운로드해서 브라우저로 열면 실제 데이터 없이 배치와 전환 버튼을 확인할 수 있습니다.

Netlify 배포 없이 검토하는 작업 브랜치입니다. 명시적인 배포 요청 전에는 main에 병합하지 않습니다.

## 소개글 / 주의사항

자기소개 아래에 소개글, 모든 작품 아래에 주의사항을 표시합니다.
DATA 시트에 type이 `about`인 행을 추가하고 value에 소개글을 입력하세요.
type이 `notice`인 행의 value에는 주의사항을 입력하세요. 셀 안의 줄바꿈은 그대로 표시됩니다.
기존 `intro` 또는 `text`는 자기소개 카드에 계속 사용됩니다. 새 내용이 없으면 안내용 자리표시 문구가 나옵니다.

## 협업작가

주의사항 바로 위에 작가별 미디어 카드와 소개 카드를 한 묶음으로 세로 배치합니다. 별도의 내부 스크롤 박스 없이 페이지 전체를 아래로 스크롤합니다. PC에서는 미디어/소개가 좌우, 모바일에서는 위아래로 표시됩니다. 아트머그 iframe이 고정 높이라면 작가 수와 글 길이에 맞춰 외부 iframe 높이도 늘려야 합니다.

| type | value |
| --- | --- |
| collab_1_name | 작가 이름 (필수) |
| collab_1_url | 해당 작가의 전체 아트머그 페이지 URL |
| collab_1_intro | 작가 소개, 줄바꿈 가능 |
| collab_1_gif | GIF 이미지 URL 하나 |
| collab_1_youtube | 유튜브 영상 URL 하나 |
| collab_1_note | 자유로운 비고 내용 (선택) |

두 번째 작가는 collab_2_name, collab_2_url 등으로 입력합니다. 3, 4…번도 같은 방식입니다. 번호 오름차순으로 나옵니다. 각 항목은 작가당 한 행씩 입력하며 중복 시 첫 번째 값을 사용합니다. 이름이 없는 작가는 표시하지 않습니다.

작가별 GIF / YOUTUBE 버튼은 독립적으로 작동합니다. 이름 클릭 시 아트머그 페이지가 새 탭으로 열립니다. URL은 artmug.kr 또는 www.artmug.kr의 http/https 주소만 허용합니다. 링크가 없거나 잘못되면 이름을 클릭할 수 없고 등록 예정 안내를 표시합니다.

비고에는 “작가님 이름 클릭 시 페이지로 이동합니다.”가 항상 표시되며, note 내용은 그 아래에 추가됩니다. 예시 미리보기에는 실존 작가 정보 대신 두 작가의 빈 카드가 표시됩니다.

## 미디어 로딩과 빈 상태

GIF/YouTube URL이 없으면 “준비 중입니다···”를 표시합니다. 빈 작품 목록에는 슬라이드 탐색 버튼을 표시하지 않습니다. GIF는 최초 로딩 시 16:9 공간을 확보하고, 이후 이미지 변경 시 이전 이미지 비율을 로딩 완료까지 유지합니다. 로딩이 끝나면 새 이미지의 원본 비율에 맞추므로 잘리지 않습니다. 원본 비율이 다르면 로딩 완료 후 높이는 달라질 수 있습니다. YouTube는 16:9 공간을 유지합니다. 실제 미디어 로드 실패는 별도의 오류 문구로 표시됩니다. 협업작가 안내 영역은 ‘비고’ 제목 없이 안내와 추가 내용만 표시합니다.

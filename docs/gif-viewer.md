# GIF 크게 보기

GIF를 클릭하거나 키보드로 선택한 뒤 Enter/Space를 누르면 확대됩니다.
오른쪽 위 ×, Esc 또는 이미지 바깥 배경 클릭으로 닫습니다.
배경은 rgba(0, 0, 0, 0.7)이며 GIF는 원본 비율을 유지합니다.

## 아트머그 iframe

기존 iframe의 다른 속성과 높이는 유지하고 allowfullscreen 속성을 추가하세요.
이미 allow 속성이 있다면 기존 권한을 보존하며 fullscreen을 추가할 수 있습니다.
브라우저/아트머그의 전체화면 정책이 허용하면 iframe 밖 화면 전체로 표시됩니다.
권한이 없거나 브라우저가 거절하면 iframe 내부 확대창으로 표시됩니다.

## 확인용 미리보기

preview/categories.html을 다운로드해 브라우저에서 여세요.
방송화면의 예시 GIF는 얀이님.gif이며 GIF 주소는 기존 Netlify의 /gif/얀이님.gif입니다.
미리보기에는 예시 시트 데이터가 들어 있습니다. 실제 Google Sheets는 수정하지 않았습니다.
